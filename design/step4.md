### 文档 4：多区域接触感知 3DGS 联合优化 (Joint Optimization)

**模块目标**：在统一坐标系下，将初始 3DGS 投射回原始未分离的真实视频上，结合物理约束进行端到端的 Loss 优化，解决 2D 先验存在的穿模、漂移和伪影问题。

**核心输入**：

- 所有前置输出：$I_{orig}$、$G_o$、$G_h$、软掩码 ($M_p, M_s, M_{object}$)、对齐的 $\mathcal{H}_i$、2D关键点 $\hat{J}_i$。

**开发任务单**：

1. **坐标系配准 (Coordinate Registration)**：
	- 编写一个可学习的 $SE(3)$ 变换模块（平移 + 旋转矩阵），将生成在规范化空间里的 $G_o$ 和 $G_h$ 对齐到文档 1 确立的绝对物理世界坐标系下。
2. **联合渲染器封装**：
	- 基于 `diff-gaussian-rasterization` 编写前向渲染代码，将变换后的 $G_o \cup G_h$ 渲染为图像 $\hat{I}_{render}$。
3. **核心 Loss 计算图构建**（**工程量最大的部分**）：
	- **多区域渲染 Loss ($L_{render}$)**：利用文档 1 提供的软掩码作为权重矩阵，分别计算可见区（严格惩罚）、主遮挡区（中度惩罚）和次遮挡区（轻度惩罚）与真实/补全视频的像素级差异。
	- **接触 Loss ($L_c$)**：计算被预测为接触的手部 3D 关节与物体 Gaussian 均值点之间的最近邻距离。
	- **2D 投影 Loss ($L_{j2d}$)**：利用相机内参，将当前 $\mathcal{H}_i$ 投影到 2D 并与 OpenPose 的 $\hat{J}_i$ 计算 $L_2$ 损失。
	- **穿模 Loss ($L_{pen}$)**：集成 Volumetric SMPL，计算物体 Gaussian 均值点进入人体 SDF 负值区域的惩罚。
	- **时序平滑 Loss ($L_{acc}$)**：计算相邻三帧之间物体位姿的加速度差异。
4. **反向传播与优化循环**：
	- 配置 Adam 优化器，设定不同 Loss 项的权重衰减与学习率策略，执行数千步的优化。
